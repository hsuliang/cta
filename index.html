⚡ 一、拿到程式後的「30 秒起手式」（首次使用必看！）

第 1 步（安裝到自己的雲端硬碟！）

💾 兩種安裝方式（任選一種）

  • 方法 A（最快・免下載）：點上方黃色按鈕「🚀 一鍵在 Google Colab 直接開啟」➔ 點左上角 「檔案 (File) ➔ 在雲端硬碟中儲存副本 (Save a copy in Drive)」 即完成安裝！
  • 方法 B（下載手動上傳）：點上方白色按鈕「📥 從 GitHub 下載 .ipynb 程式檔」➔ 打開 Google Colab 點選「上傳 (Upload)」或拖曳進自己的 Google 雲端硬碟 Colab Notebooks 資料夾，再用 Colab 開啟。
第 2 步（語音轉錄必開）

⚙️ 確認開啟免費 T4 GPU 加速

若要將「音檔或 YouTube 影片」轉成逐字稿：

  • 點選頂部選單「執行階段 (Runtime) ➔ 變更執行階段類型」，硬體加速器選擇 T4 GPU 後按儲存。
  • 💡 若您手邊已經有現成的 .srt 字幕或 .txt 文字檔，連 GPU 都不用開，直接用預設 CPU 跑步驟 2B 即可！
第 3 步（免費申請）

🔑 準備一把自己的 Gemini API Key

步驟 4 的 AI 全媒體創作需要您自己的免費 Gemini 金鑰：

  • 前往 Google AI Studio 金鑰頁面 登入 Google 帳號，點擊 Create API key 即可免費複製。
  • 貼入步驟 4 時預設以 •••••••• 密碼遮罩保護（絕不寫入程式碼外流），且若免費金鑰無高階模型權限，系統會自動無縫降階至可用模型，絕不中斷！

🔀 二、依您手邊的素材，選擇操作路線（點擊下方卡片切換教學）

1

🟦 步驟 1：檢查 GPU 與安裝套件

點擊左側的 ▶ 執行鈕，首次執行約需 1 分鐘安裝語音辨識引擎與 YouTube 下載器。（同一次連線期間，連續轉錄多支音檔時無須重複執行步驟 1！）

2A

🟩 步驟 2A：選擇音檔／YouTube 來源 & 詞庫設定

支援 4 種音訊來源模式（點擊 ▶ 後會彈出對應的互動選單）：

  • Google 雲端硬碟（單一音檔 — 互動式下拉選單）：路徑留空直接執行，自動掃描您的雲端硬碟音檔供下拉挑選，免打字！
  • 🎬 YouTube 網址直轉：貼上 YouTube 影片或直播連結，自動抓音軌並記住 11 碼影片 ID（後續寫 Blog 時會自動在文章頂部嵌入 16:9 影片播放器！）。
  • Google 雲端硬碟（資料夾整批全自動轉錄）：一次選取整個資料夾，全自動逐集轉錄並分資料夾歸檔。
  • 💻 本機上傳：直接從電腦挑選音檔或影片上傳。
3

🟨 步驟 3：開始語音辨識與字幕清洗（支援雙引擎自由切換）

點擊 ▶ 後會顯示雙引擎語音辨識選擇台（先選好引擎與模型大小，按下綠色按鈕才會按需載入該模型，絕不浪費 GPU 顯存）：

  • ⚡ Faster-Whisper（預設，可選 large-v3-turbo / large-v3 / medium / small）：國語與中英夾雜速度最快、時間軸最穩。
  • 🇹🇼 Qwen3-ASR（可選 1.7B / 0.6B ＋ Qwen3-ForcedAligner-0.6B 對軸搭檔）：專攻台語／國台語夾雜辨識，且轉錄完會自動釋放顯存，隨時可切換另一引擎重測！
4

🟧 步驟 4：雙引擎 AI 全媒體創作工作台（支援「先選標題再全媒體聯動」）

點擊左側 ▶ 開啟三合一互動控制中心：

  • 在【🔐 ① 金鑰、情境快捷鍵 & 啟動 AI】分頁貼上 Gemini API Key，點選情境快捷鍵後按 「🚀 開始執行 AI 全媒體創作」。
  • 🎯 兩段式定調流程：系統會先完成字幕校對＋全本順稿，並產出 9 組爆款標題 讓您互動點選與微調；拍板定案後按下第二階段按鈕，後續的 YT 簡介、Blog 專欄、社群貼文、輪播圖與封面大字 就會 100% 圍繞您選定的標題聯動產出！
5

🟪 步驟 5 & ⬜ 步驟 6：下載全媒體創作包 ZIP & 清理還原畫面

所有檔案在步驟 4 完成瞬間就已自動存回您雲端硬碟的 轉錄成果_ㄚ亮笑長助手/{音檔同名資料夾}/ 中！您也可以按步驟 5 下載 ZIP 壓縮包到電腦，或按步驟 6 一鍵收合所有面板並清空暫存，準備處理下一集。

⚡ 極速直通秘訣：當您手邊已經有剪映匯出的 .srt、YouTube 下載的字幕、或會議紀錄 .txt 時，完全不需要開啟 GPU，也完全不用執行「步驟 1」與「步驟 3」！
2B

🟦 步驟 2B：現成 SRT / TXT 匯入（免開 GPU，完成後直接跳步驟 4）

直接拉到「2B. 現成 SRT / TXT 匯入」區塊，選擇匯入方式後點擊左側的 ▶：

  • 📂 Google 雲端硬碟下拉選單：自動掃描您雲端硬碟內的 .srt / .vtt / .txt / .md 文稿供下拉挑選。
  • 💻 本機上傳：直接從電腦選取 .srt 或 .txt 檔上傳（若為 SRT 會 100% 保留原始時間碼；若為純文字 TXT 會自動依標點智慧分句）。
  • ✍️ 直接貼上純文字／會議筆記：在畫面上彈出的多行文字框直接貼上文稿內容。
4

🟧 直接跳到「步驟 4：雙引擎 AI 全媒體創作工作台」！

完成步驟 2B 後，請直接跳過步驟 3，點擊步驟 4 左側的 ▶，貼上 Gemini API Key 後點擊 「🚀 開始執行 AI 全媒體創作」，30 秒內即可產出全套作品！（甚至也可以直接在步驟 4 的【📝 分頁 ③：免轉錄！直接匯入現成 SRT / TXT】直接選檔或貼文字！）

告別過去十幾個零碎檔案的混亂！每一集執行完畢後，系統會自動在您的 Google 雲端硬碟 Colab Notebooks/轉錄成果_ㄚ亮笑長助手/ 下，建立一個「與音檔同名的專屬子資料夾」，裡面只存放最精華的 3 個黃金核心檔案：

🔗 四、進階神技：一鍵推送 Google Blogger 草稿夾 & 詞庫永久記憶

📝 如何將寫好的 Blog 專欄文章「一鍵推送到自己的 Google Blogger 後台草稿夾」？

本工具支援直接連結您個人的 Google Blogger 網誌，自動抓取您名下的網誌清單，並將排好版的 HTML 文章（含 YouTube 影片框、30 秒導讀卡、金句框、回顧表格與分類標籤）一鍵送進 Blogger 草稿夾！
🛡️ 帳號安全隔離：您的授權資訊只會存在您自己雲端硬碟的 Colab Notebooks/CTB_詞庫設定_永久記憶/blogger_auth.json 中，就算跑 Colab 的帳號與管理 Blogger 的帳號不同也能跨帳號綁定！

  1. 在 Colab 執行「步驟 4」後，點選控制中心的第二個分頁：🔗 ② Blogger 一鍵連結 & 網誌選單。
  2. 先點一下這顆按鈕複製 Blogger 權限網址： （https://www.googleapis.com/auth/blogger）
  3. 開啟 Google 官方乾淨版授權頁 👉 https://developers.google.com/oauthplayground/
  4. 在網頁左下角的 Input your own scopes 框框貼上剛剛複製的權限網址，點擊右側藍色的 Authorize APIs 按鈕，並選擇擁有 Blogger 網誌的那個 Google 帳號登入允許。
  5. 進入 Step 2 後，點擊藍色的 Exchange authorization code for tokens，將右側產生的 Access token（或整段含 refresh_token 的 JSON）複製起來。
  6. 貼回 Colab 的 🔑 Blogger 授權： 框框，按下 「🔗 連結並抓網誌清單」！下拉選單就會自動列出您的網誌，隨時點擊 「📤 一鍵推送至【草稿夾】」 即可直接進 Blogger 後台預覽發布！
📖 如何建立自己的「錯字替換規則 & 專有名詞庫」雲端永久記憶？
  • 方法 1（直接在步驟 2A / 2B 表單填寫）：在 錯字替換規則（格式：錯字->正字, 錯字2->正字2）與 正向專有名詞 填入您常用的姓名、學校或課程名稱。只要執行過一次步驟 2A 或 2B，系統就會自動將它們寫入您個人雲端硬碟的 Colab Notebooks/CTB_詞庫設定_永久記憶/ 資料夾中永久保存！
  • 方法 2（與網頁版 ctb.52hal.cc 雙向互通）：如果您在網頁版已經匯出過 Batch_Replace_Rules.json 或 AI_Terminology_Rules.json，只需在步驟 2A / 2B 勾選 ☑️ 從電腦上傳匯入詞庫JSON設定檔 執行一次，上傳後就會永久記憶在您的雲端硬碟，之後每次開啟都會全自動載入！

❓ 五、常見問題 FAQ 急救包

Q1：我貼上的 Gemini API Key 或 Blogger 授權，會不會被別人看到？
100% 不會！
1. 金鑰輸入框採用 •••••••• 密碼遮罩設計，只暫存於您當次執行階段的記憶體中，絕對不會寫入 .ipynb 程式碼檔案。
2. 詞庫與 Blogger 授權記憶則是存放在您自己個人的 Google 雲端硬碟裡，其他人打開程式時只會讀取他們自己的雲端硬碟，彼此完全獨立安全。
Q2：我的 Gemini API Key 是免費版，沒有最高階模型的權限怎麼辦？
完全不用擔心！程式內建「智慧自動降階梯隊（Auto-Downgrade Ladder）」與「6 秒安全請求間隔護欄」。當系統偵測到您的 API Key 無法呼叫高階模型或額度已滿時，會在 1 秒內自動無縫切換至免費高速的 gemini-3.5-flash-lite / 2.5-flash-lite 模型繼續完成所有創作，絕不會報錯中斷！
Q3：為什麼我按下步驟 4 的「▶」後沒有馬上開始跑 AI？
這是為了防止「按 ▶ 自動開跑」與「點按鈕開跑」重複執行兩次！
當您按下步驟 4 左側的 ▶ 時，系統會先為您打開「三合一互動控制中心」，讓您可以先確認或切換情境快捷鍵、貼上金鑰或選取 Blogger 網誌，確認無誤後點擊綠色的 「🚀 開始執行 AI 全媒體創作」 按鈕就會正式啟動！
Q4：跑完一集之後，想要把畫面清空、接著轉錄下一集該怎麼做？
請直接拉到最下方執行「⬜ 6. 清除本次暫存資料並將畫面還原至初始狀態」！它會自動清除後台暫存檔（不影響已存回雲端硬碟的成果），並一鍵關閉收合前面展開的所有互動面板與預覽畫面，接著您就可以直接回到步驟 2A 或 2B 挑選下一集音檔或文稿（無須重跑步驟 1）！
Q5：使用過程中出現「自動儲存失敗。這個檔案已從遠端更新或已在另一個分頁中更新」該怎麼辦？
這是 Google Colab 保護檔案不被覆蓋的安全提醒（通常發生在同時開了兩個分頁，或遠端檔案剛被更新同步）：
1. 如果您沒有自己改寫程式碼，只是剛才在跑轉錄：請直接按 F5 重新整理網頁（若跳出提示請選「離開／重新載入」）。您已經存進雲端硬碟 轉錄成果_ㄚ亮笑長助手/ 與 CTB_詞庫設定_永久記憶/ 的檔案 100% 都不會遺失！
2. 如果您確實有在該分頁手動改過程式或參數：請先點選左上角 「檔案 (File) ➔ 在雲端硬碟中儲存副本」 另存新檔保住修改，再關閉原本的分頁即可。
💡 小技巧：平常要跑轉錄時，建議從「檔案 ➔ 儲存副本」另存一份日常工作專用檔來跑，就不會與母版更新或其他分頁衝突！
